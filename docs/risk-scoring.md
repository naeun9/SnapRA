# 위험성 산정 규칙

위험성평가표의 숫자는 임의로 정하면 문서 전체가 신뢰를 잃는다. 이 문서는 SnapRA 가
쓰는 산정 규칙과 그 근거, 그리고 의도적으로 **채택하지 않은** 선택지를 적는다.
구현은 [`src/risk_scoring.py`](../src/risk_scoring.py) 한 파일에 모여 있다.

| | |
| --- | --- |
| 척도 | 3 × 3 (빈도 1~3 × 강도 1~3 = 위험성 1~9) |
| 등급 | 1~2 낮음 / 3~4 보통 / 6~9 높음 (KRAS 기준) |
| 입력 | 현장 사진 1장 + 시나리오 ID + VLM 판정(Task B) |

## 1. 척도를 3×3으로 한 이유

KRAS(위험성평가 지원시스템)의 기본 척도가 3×3이다. 5×5를 쓰려면 작업 높이·중량·노출
시간 같은 정량 정보가 필요한데, 우리 입력은 사진 한 장과 시나리오 ID뿐이다.
**없는 정밀도를 꾸며내지 않기 위해** 3×3을 쓴다.

## 2. 강도(S) — 전 유형 3으로 균일하다

> **본 데이터셋은 5대 중대재해 유형만 포함하므로 강도(S)는 전 유형 3으로 균일하다.
> 등급 변별은 빈도(F)에서 발생한다. 경미 재해 유형이 포함된 일반 현장으로 확장하면
> 강도가 변별력을 갖는다.**

이 사실을 숨기지 않는다. 강도가 상수인 표를 "강도도 평가했다"고 내놓으면 심사에서
바로 드러난다.

| 코드 | 유형 | S | 근거 |
| --- | --- | --- | --- |
| A | 추락 | 3 | 건설업 사고사망 1위 유형(떨어짐). 고소 추락은 사망 직결 |
| B | 낙하 | 3 | 산안법상 '물체에 맞음' 중대재해 유형. 중량물 낙하는 보호구로 막히지 않음 |
| C | 협착 | 3 | 중장비 끼임은 사망·절단 직결, 2차 방어수단 없음 |
| D | 화재 | 3 | 화상·질식. 실내·밀폐 공간에서는 다수 피해 |
| E | 전도 | 3 | 중장비·가설물 전도는 깔림 사망 직결 |

### 낙하를 2로 낮추는 안을 기각한 이유

초안에서는 "안전모·방호선반·방지망이 2차 방어로 작동하므로 같은 조건에서 치명률이
상대적으로 낮다"는 근거로 낙하에 2를 부여했다. 검토 결과 기각했다.

1. **안전 문서에서 위험을 낮게 잡는 방향의 오류는 허용되기 어렵다.** 안전모가 있어도
   중량물 낙하는 사망 사고다.
2. **2차 방어수단의 존재를 강도 감점 근거로 쓰려면 그 완화 효과를 측정한 자료가
   있어야 한다.** 우리에게는 없다. 근거 없는 감점은 숫자를 꾸민 것이다.
3. **"왜 낙하만 낮은가"에 답할 수 없다.** 산안법상 떨어짐·맞음 모두 중대재해 유형이다.

이 판단은 아래 4절(confidence 를 점수에서 뺀 것)과 같은 방향이다. 불확실할 때
위험을 낮추지 않는다.

`SEVERITY_BY_TYPE` 은 설정으로 남겨 두었으므로 현장 성격에 맞게 조정할 수 있다.

### 한계

작업 높이와 중량 정보가 입력에 없어 강도를 더 세분할 수 없다. 사진만으로 2층과 10층을
구분하지 않는다. 고층 작업이 많은 현장은 강도를 상향 조정해야 한다.

## 3. 빈도(F) — 시나리오 설명 문구로 결정

`tables.SCENARIOS` 의 N-nn 설명은 "무엇이 어떻게 잘못되었는지"를 일정한 어법으로
적고 있다. **50종 전수를 읽고 6개 규칙군으로 갈랐으며 50/50 전부 적용된다**(미적용 0).

| F | 분류 | 키워드 | 종수 | 근거 |
| --- | --- | --- | --- | --- |
| 3 | 방호장치·신호수 부재 | 미배치, 미설치, 미사용 | 17 | 방호수단이 0이라 작업 시간 전체가 노출 구간 |
| 3 | 근로자가 위험구역 내 | 위험 반경 내, 동시작업, 최상단에서 작업, 열려 있는 | 8 | 추가 조건 없이 현재 상태에서 재해 가능 |
| 3 | 불안정 승강설비 사용 | 간이 사다리 | 1 | 비계 발판 위 사다리는 디딤면 자체가 불안정 |
| 2 | 설비 불량·기준 미준수 | 불량, 미흡, 미준수, 부적절 | 13 | 설비가 존재해 부분 기능. 특정 조건에서 실패 |
| 2 | 불안정 적재·설치 | 과적재, 적치, 적재물 위, 단부 위, 위험물 배치 | 7 | 붕괴·낙하에 외력이나 추가 동작이 필요 |
| 2 | 가연물·열원 근접 | 인화성, 난로, 산소절단기 | 4 | 착화원이 실제로 작동해야 재해로 진행 |

**F=1 은 규칙으로 부여하지 않는다.** 이 데이터의 N 시나리오는 모두 "이미 발생한
불안전 상태"를 찍은 것이므로 가능성이 낮다고 볼 근거가 없다. 규칙에 걸리지 않는 문구는
F=2(기본값)로 두고 `검토필요` 로 표시해 사람이 확인하게 한다.

## 4. confidence 는 위험성 점수에 넣지 않는다

VLM 의 confidence 를 빈도에 곱하는 안을 검토했으나 채택하지 않았다. 둘은 다른 것을
재는 값이다.

| 값 | 측정 대상 |
| --- | --- |
| confidence | "모델이 이 상태를 맞게 봤는가" — 측정의 신뢰도 |
| 빈도 | "이 상태가 재해로 이어질 가능성" — 위험의 속성 |

곱하면 **"모델이 확신하지 못하니 위험이 낮다"** 는 결론이 나온다. 안전 문서에서 이
방향의 오류는 허용되지 않는다. 확신이 없을 때 필요한 것은 점수를 깎는 게 아니라 사람이
현장에서 확인하는 것이다.

그래서 confidence 는 분리해 내보낸다.

| 출력 | 규칙 |
| --- | --- |
| 신뢰도 등급 | ≥0.8 상 / ≥0.6 중 / 그 미만 하 |
| 검토필요 플래그 | confidence < 0.7, 또는 판정이 "판단불가", 또는 빈도 규칙 미적용 |

위험성 점수는 "상태가 사실"이라는 가정 위에서 산정한다.

## 5. 조치 기한

| 위험성 | 등급 | 기한 |
| --- | --- | --- |
| 6~9 | 높음 | 즉시 개선 (3일 내) |
| 3~4 | 보통 | 계획 개선 (30일 내) |
| 1~2 | 낮음 | 현행 유지 (수시 점검) |
| — | 확인필요 (판단불가) | 현장 확인 후 확정 |

## 6. 개선대책 문구 — Y 설명을 그대로 쓴다

**Y/N 쌍이 그대로 "현재 상태 → 목표 상태"가 된다.** `N-03`(개구부 덮개 설치 불량)
판정이면 개선대책은 `Y-03`(개구부 덮개 설치)이다. `tables.scenario_pair()` 로
끌어오므로 문구를 새로 짓지 않는다.

평가표에서 모델이 생성한 칸은 **"현재 안전조치"(Task B 의 `observed`) 하나뿐**이다.
나머지 문장은 전부 데이터셋의 시나리오 정의를 인용한 것이다. 그래서 어느 칸이 사람이
정의한 것이고 어느 칸이 모델 출력인지 구분된다.

### 조치 문구 변환 — 4종만

Y 설명 50종 중 46종은 그대로 조치 문구가 된다(설치 15 / 배치 15 / 작업 9 / 적재 2 등).
부정 표현으로 끝나는 **4종만** 행동 지시문으로 읽히지 않아 변환한다.

| ID | 원문 (목표 상태) | 개선대책 (변환) |
| --- | --- | --- |
| Y-08 | 이동식 비계 발판 위 간이 사다리 **미설치** | 이동식 비계 발판 위 간이 사다리 **설치 금지 / 제거** |
| Y-11 | 시스템 비계 위 낙하 위험물 **미배치** | 시스템 비계 위 낙하 위험물 **배치 금지 / 제거** |
| Y-15 | 거푸집 단부 위 적재물 **미배치** | 거푸집 단부 위 적재물 **배치 금지 / 제거** |
| Y-32 | 실내 마감 작업 시 근처 난로 **미설치** | 실내 마감 작업 시 근처 난로 **설치 금지 / 제거** |

적용 규칙: `미배치 → 배치 금지 / 제거`, `미사용 → 사용 중지`, `미설치 → 설치 금지 / 제거`
(`미사용` 은 Y 설명에 해당 항목이 없어 실제로는 발동하지 않는다.)

**자동 치환이 아니라 손으로 고른 표다.** 정규식 치환은 부정어가 없는데도 어색한 문구
(예: `Y-10 작업자가 사다리 최상단 밑단에서 작업`)를 건드려 뜻을 바꿀 위험이 있다.
`tables.py` 가 바뀌어 새로운 부정 표현이 들어오면 `uncovered_negatives()` 가 경고로
알린다 — 조용히 넘기지 않는다.

**원문은 버리지 않는다.** 근거 열에 병기한다. 열이 늘어나지 않으면서 인용 근거가 남는다.

```
N-11 (시스템 비계 위 낙하 위험물 배치) / 낙하 / Y-11 (시스템 비계 위 낙하 위험물 미배치)
[조치 문구로 변환] / 산안법 조항 매핑 TODO
```

### 검토 대기 중인 한 건

`Y-02 개폐형 발판이 닫혀 있는 상황` 은 부정 표현이 없지만 상태 서술형이라 조치 문구로
읽히지 않는다. 변환하려면 승인된 매핑표(미배치/미사용/미설치)를 넘어 문구를 새로 지어야
하므로 **원문 유지**로 두었다. 바꿀지는 검토 사항이다.

## 7. 아직 없는 것

- **산업안전보건기준에 관한 규칙 조항 매핑** — 근거 칸에 시나리오 ID·사고유형·목표
  상태 ID 만 적고 조항은 TODO 다. 법정 문서로 쓰려면 이 매핑이 필요하다.
- **KRAS 서식 정렬** — 열 구조만 잡았고 공식 서식 양식에 맞추는 작업은 남았다.
- **빈도에 노출 인원·시간 반영** — 사업장 프로파일에 인원 필드가 있지만 아직 점수에
  반영하지 않는다. 반영하려면 작업별 투입 인원 데이터가 필요하다.
